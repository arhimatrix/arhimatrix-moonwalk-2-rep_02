# Moonwalk 2.0 · Report 02

Scrolling research site for Moonwalk 2.0, towards a permanent human presence on the Moon.
Phase 0 work at the Space Robotics Lab, Tohoku University.

**Part A · Site and pavement**
- Zooming tour from the whole Moon to the south pole; four candidate sites, each mapped and scored
- One hexagonal block family set by the tilt of its side faces, with the Grasshopper definition and GhPython code
- Graded pavement: closed core, tilted rings, dust pockets with electromagnets
- Isaac Sim: pads held only at the rim

**Part B · Structures**
- Grounding: how walls and columns sit in the pavement
- Wall A and Column A from the same blocks, with Isaac Sim moonquake tests
- The Horizon shell: the same hexagonal block mapped onto an 8 m dome that aims to build without centering, with an interactive explorer (span, rise, tilt, block size)
- Quick checks and next steps
